# Clientes

Uma pasta por cliente, com o slug igual ao do Drive e do repositório:

```
04-clientes/<slug>/
├── cliente.md      ← nota viva: escopo, exceções, estado (de _modelos/cliente)
├── kanban.md       ← tarefas (de _modelos/kanban)
├── log.md          ← histórico de sessões (de _modelos/log)
├── reunioes/       ← uma nota por reunião
├── campanhas/      ← uma nota por campanha
├── fontes/         ← originais, nunca editados: transcrições, conversas, documentos
└── entregas/       ← briefs, estratégias, copies, documentos de entrega
```

JurIA e Mobiletec são dois clientes, com uma pasta cada: `juria`
e `mobiletec` (decisão do Guilherme, 04/11/2026).
