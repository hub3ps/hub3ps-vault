# Vault Hub3Ps

Rascunho do cérebro da agência, para virar um repositório próprio depois da
revisão. As regras de uso pelo Claude estão em [CLAUDE.md](CLAUDE.md).

## Instalar
1. Instale o Obsidian e abra esta pasta como vault.
2. Em Configurações, Plugins da comunidade, instale e ative: **Obsidian Git**,
   **Dataview** e **Kanban**.
3. No Obsidian Git: ative o backup automático a cada 5 minutos e o pull ao abrir.
4. Opcional: Obsidian Sync, só para o celular.

## Começar
Abra [INICIO.md](INICIO.md). Ele lista clientes, pendências e pipeline.
