# Agentes de IA

Faz parte do [[catalogo]]. Ativado pelo [[motor]] quando o serviço está no escopo do cliente.

## Pré-requisitos
Viram o checklist de onboarding do cliente.

- [ ] Base de conhecimento
- [ ] Conversas reais
- [ ] Canal na API oficial
- [ ] Regras de handoff
- [ ] Política da Meta para o segmento (políticos não podem usar a API do WhatsApp Business)
- [ ] Conta PJ para checkout, se houver pagamento

## Implantação
Feita uma vez, na ordem.

1. Persona e prompt
2. Fluxos: agendar, qualificar, vender
3. Integrações: agenda, pagamento, CRM
4. Testes e go-live

## Entregáveis

- Agente no ar
- Base de conhecimento
- Mapa de fluxos

## Rotina

| Cadência | O quê |
|---|---|
| Semanal | revisar conversas |
| Mensal | atualizar a base e relatório |

## Ferramentas e skills

- n8n, Supabase
- WhatsApp Cloud API ou Evolution
- Claude

## Indicadores
Entram no relatório do cliente.

- Conversas
- Resolvidas sem humano
- Agendamentos e vendas
- Custo por conversa
